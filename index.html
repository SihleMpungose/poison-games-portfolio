THE JOURNEY

Progress built one project at a time.

My goal is not to skip the beginner stage—it is to use it well. Each project gives me a new problem to solve and a stronger foundation for the next one.

01
FOUNDATION

IT, Java and software testing

My IT background, Java learning and QA practice gave me a foundation for logic, testing behaviour and breaking large problems into smaller ones.

02
BUILD

Turning ideas into playable systems

Mobile MMA Sim became the project where I began connecting progression, fights, training, contracts, saves and user interface into one playable experience.

03
RELEASE

Learning what happens after development

I began preparing web, Windows and Android builds, testing releases, handling store requirements, managing versions and getting projects onto real devices.

04
EXPAND

Trying different forms of game development

Interactive fiction introduced me to narrative state and consequences, while other projects are helping me explore new systems and 3D development.

05
NOW

Building stronger fundamentals

I’m continuing to improve programming, structure, UI, mobile development, 3D skills and the discipline needed to finish increasingly polished games.
