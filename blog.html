17 NOV 2026DEVELOPMENT PROGRESSSLOW POISON GAMES

November progress: live-game support, PC builds and active testing.

Mobile MMA Sim mobile reliability has improved after the recent installation, update and save work, with no recent reports of the earlier problems. The separate PC Edition has reached an internal v1.0.0 candidate after long-form automated career testing, but Windows acceptance is still open and the build is not a Steam release.

TrackBorn is actively developing again: a recent internal PC build reached v0.6.0 and passed automated progression/regression checks, with Windows testing still pending. Seed Isles remains in private development, but I am not publishing a build milestone until there is something appropriately tested and ready to show.

Unwritten Meridian — Book One is back in focused testing while remaining in Early Access. Beneath the Borrowed Light remains live on itch.io, with an internal v0.23.7 audio-focused candidate passing 150 automated checks before real-browser/device listening.

Android Demo: the Mobile MMA Sim Android demo is targeted for 30 November 2026, subject to Google Play testing, review and approval. It remains a target—not a guaranteed store launch date.
17 NOV 2026PC EDITIONINTERNAL BUILD

Mobile MMA Sim PC reaches a controlled v1.0.0 candidate.

The Windows-first edition has moved beyond the initial framework into a broader internal candidate covering long-term career progression and title/ranking continuity. The latest test record passed 106 of 108 bundled and independent automated checks, with two intermittent failures still open.

Not release-certified: native Windows launch, save/recovery behaviour, display/layout, keyboard/focus, performance and visual acceptance still need to be run on the actual Windows build before v1.0 testing can be signed off.
29 OCT 2026POST-LAUNCHMOBILE MMA SIM

The post-launch phase is now about depth, stability and polish.

Recent work has moved beyond the launch itself. I have been testing fight balance more deeply across striking, grappling and clinch situations, checking simulation speed and UI responsiveness, improving save-loading reliability, and tightening the Early Access supporter cosmetic experience.

Why this matters: the goal is not to add features faster than the game can support them. The priority is making existing systems feel fair, responsive and dependable before the next public update.

SEP 2026LESSONPUBLISHING

Public builds changed how I think about “done”.

Testing a game yourself is different from supporting a build after other people can install it. Store tracks, device behaviour, versioning, saves and player reports have made release discipline a much bigger part of how I approach development.

Portfolio vs devlog: the portfolio is the stable overview; this page records dated changes. That separation keeps the site useful instead of repeating the same status paragraph in every section.
