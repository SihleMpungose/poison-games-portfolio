# Poison Games / SihleM — Game Development Portfolio

Static personal portfolio website for SihleM / Poison Games.

## Files

- `index.html` — landing-page portfolio
- `blog.html` — separate development blog
- `styles.css` — shared dark/red/blue visual system
- `script.js` — mobile navigation, reveal effects, active navigation and scroll progress
- `assets/` — favicon and official project artwork used by the portfolio

## Project links included

- Mobile MMA Sim demo: https://sihlem.itch.io/mobilemmasim
- Mobile MMA Sim full edition: https://sihlem.itch.io/mobilemmasim-full
- Unwritten Meridian — Book One: https://sihlem.itch.io/unwritten-meridian
- Poison Games itch.io profile: https://sihlem.itch.io/

## Hosting

Upload the contents of this folder to a static host such as GitHub Pages, Cloudflare Pages or Netlify. Keep `index.html`, `blog.html`, `styles.css`, `script.js` and the `assets` folder together at the site root.

If hosting through GitHub Pages from a repository branch, publish the repository root (`/`).
